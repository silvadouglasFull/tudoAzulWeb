# Tudo Azul - Landing Page

This project is a front-end for the landing page to promote the services offered by the company tudo azul.

## 🚀 About the Project

This is a modern and responsive landing page built to showcase the pool cleaning and maintenance services of the "Tudo Azul" company. The goal is to attract new customers by presenting the company's services, values, and contact information in a clear and appealing way.

**GitHub Repository:** [https://github.com/silvadouglasFull/tudoAzulWeb](https://github.com/silvadouglasFull/tudoAzulWeb)

### ✨ Features

- **Responsive Design:** Works perfectly on desktops, tablets, and mobile devices.
- **Modern UI:** Built with shadcn/ui and Tailwind CSS for a clean and professional look.
- **Interactive Sections:** Smooth scrolling and animations to enhance the user experience.
- **Calls to Action (CTAs):** Buttons to easily contact the company via WhatsApp.

## 🛠️ Technologies Used

This project was built with the following technologies:

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Lucide React](https://lucide.dev/guide/packages/lucide-react) (for icons)

## 🏁 How to Run

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm (or yarn/pnpm) installed on your machine.

- npm
  ```sh
  npm install npm@latest -g
  ```

### Instalação

1.  Clone o repositório
    ```sh
    git clone https://github.com/silvadouglasFull/tudoAzulWeb.git
    ```
2.  Navegue até o diretório do projeto
    ```sh
    cd tudoAzulWeb
    ```
3.  Instale os pacotes NPM
    ```sh
    npm install
    ```

### Executando o Projeto

Para executar o projeto em modo de desenvolvimento:

```sh
npm run dev
```

Isso iniciará o servidor de desenvolvimento, geralmente em `http://localhost:5173`.

### Compilando para Produção

Para criar uma build de produção:

```sh
npm run build
```

Este comando irá gerar uma pasta `dist` com os arquivos otimizados para implantação.
